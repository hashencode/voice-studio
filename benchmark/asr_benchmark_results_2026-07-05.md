## Parameter Benchmark Design

The benchmark now separates three measurement classes:

| Class | Meaning | Use |
| --- | --- | --- |
| `warm` | Recognizer is loaded once, warmed with an unrecorded decode, then reused. | Primary parameter ranking. |
| `cold` | Recognizer load is part of the measured operation. | First-use cost measurement. |
| `current` | Approximates current business-route loading behavior, such as realtime per-segment recognizer load. | Reality check against current implementation. |

Default warm profiles:

| Profile | Route | Purpose |
| --- | --- | --- |
| `standard_whole_warm_t2` | standard | Whole-file Paraformer decode with shared warm recognizer. |
| `standard_vad_silero_warm_t2` | standard | Silero VAD segmentation with shared warm recognizer. |
| `realtime_rms_warm_baseline_t2` | realtime replay | Replays fixture audio through RMS VAD-style segmentation with shared warm recognizer. |
| `realtime_silero_warm_default_t2` | realtime replay | Replays fixture audio through Silero segmentation with shared warm recognizer. |

Cold/current profiles available for targeted runs:

| Profile | Route | Purpose |
| --- | --- | --- |
| `standard_whole_cold_t2` | standard | Measures whole-file decode with per-case recognizer load. |
| `realtime_rms_current_baseline_t2` | realtime replay | Measures RMS realtime replay with per-segment recognizer load, approximating the current realtime route. |

Known bias controls:
- Do not compare warm, cold, and current rows as if they measure the same thing.
- Rotate or randomize profile order for large exhaustive sweeps to reduce thermal and cache-order bias.
- Treat simulator timing and memory as screening evidence; true-device复核 remains deferred.
- Watch segment count, empty segments, p95 segment decode time, total recognizer load time, queue/drop behavior, and operation RTF together.
- Keep warm-up policy, filesystem cache state, Android background load, emulator CPU allocation, audio sample rate, normalization, and transcript cleanup fixed across comparable runs.
- The current committed fixtures are stable but limited; add more fixture diversity before treating a profile as globally optimal.
