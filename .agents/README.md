# Agent 工作目录

| 目录 | 用途 | 版本管理 |
| --- | --- | --- |
| [memories/](memories/README.md) | 获准保存的候选记忆与已复核保留的历史证据 | 说明与获准保存的非敏感条目可以纳入 Git |
| `tmp/` | 按日期、任务保存临时脚本、日志和中间核对材料 | 仅保留 `.gitkeep`，其余内容递归忽略 |

管理正文见 [经验与记忆维护](../docs/ai/development-rules.md#经验与记忆维护)，任务入口见 [AI 开发导航](../docs/ai/README.md)。本目录不另维护开发规则或验收结论的副本。

整个仓库共用这套目录；monorepo 的记录注明所属应用、模块与适用范围，不为每个包复制一套。2026-10-22 存量整理已完成，逐项结果见 [结项记录](../docs/plans/2026-10-22-memory-cleanup-proposals.md)。保留的经验、设计来源与验收证据已结项，不再重复列为下一批；后续新增候选或新的清理范围仍按原授权流程确认。

调试与验收截图继续使用 `.artifacts/screenshots/<YYYY-MM-DD-任务>/`。需要版本管理的正式记录放在项目既有文档目录；临时目录中的材料不能作为唯一的长期记录。本次目录补齐不设置定时复核。
