# PC 端验证入口

适用范围：`apps/desktop-electron`。根 [AGENTS](../../../AGENTS.md) 的授权、规则发现和工作区约束继续生效。

本页只按 PC 端职责定位既有检查，不新设测试等级、阈值或发布条件。详细政策仍以 [仓库验证标准](../../../docs/standards/verification.md) 为准，命令和测试清单读取当前 [package.json](../package.json)。

## 按影响选择

- 文档：差异、链接和适用范围，不启动测试、构建或 GUI。
- Renderer：选择实际变化的交互、布局及 Feature / Shell 消费者；源文件读取、IPC 和样式依赖不能只靠静态 import 图推断。
- Main / Preload / Shared：覆盖桥接校验、业务边界、权限与生命周期消费者，按根政策决定是否扩大到包级检查。
- 原生、资源、跨端协议：核对实际反向消费者和身份，使用对应原生、worker 或协议门禁；本端通过不能替代移动端或跨端证据。

## 证据边界

源代码检查不代表渲染通过。涉及可见结果的验证须先获得根 AGENTS 要求的本次明确授权；未获授权时只做允许的非视觉检查并说明限制。原生处理、资源身份与发布 candidate 按原专属门禁执行。

原测试、视觉基准与历史验收均保留原位和适用条件。本轮新增文档不代表重新通过任何产品验收。
