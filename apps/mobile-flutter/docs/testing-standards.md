# App 端验证入口

适用范围：`apps/mobile-flutter`。根 [AGENTS](../../../AGENTS.md) 的授权、规则发现和工作区约束继续生效。

本页只定位移动端受影响检查；唯一详细验证政策仍是 [根验证标准](../../../docs/standards/verification.md)，不另建等级、数量目标或整仓必跑清单。

## 检查选择

- 文档：检查差异与引用，不执行 Flutter 分析、测试、构建或设备操作。
- App 行为：按根政策先运行缓存守卫，再从本端目录选择定向分析与相关 Flutter 测试；当前测试入口见 [本端测试目录](../test)。
- 共享包：按 workspace / path 依赖和实际引用界定反向消费者；纯 Dart、Flutter 包及原生桥接分别采用根政策中对应检查，不套用 Electron 测试命令。
- 跨端或原生接口：同时核对原协议、状态与平台消费者，不只测当前 UI。

## 设备与交付范围

音频权限、真实采集、播放、平台媒体与模型处理需要相应平台证据；纯逻辑或 Widget 测试不能代替设备。任何视觉与设备过程仍须根 AGENTS 的本次授权。

选择条件、命令去重与扩大范围仍按根政策；历史记录的设备、日期和未完成项保留，本轮文档整理不刷新验收。
